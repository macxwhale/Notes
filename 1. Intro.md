## What is an API?

**API** stands for **Application Programming Interface**.

An API:

* Defines a set of **rules and capabilities** that allow two systems to communicate.
* Enables systems to **exchange or manipulate data** programmatically.

Most users interact with software through a **User Interface (UI)** rather than directly with APIs. However, APIs operate behind the scenes in nearly all software systems.

**Example:**
When a user clicks the “Send” button in an email application, the application uses an API to instruct the email server to deliver the message.

---

## Web APIs, Clients, and Servers

APIs come in many forms, but this course focuses specifically on **Web APIs**.

Web APIs:

* Enable communication between software applications over a **network or the internet**.
* Use the **HTTP protocol**, the same protocol used by web browsers to load web pages.

The communication model consists of:

* A **client**, which sends a request.
* A **server**, which processes the request and sends back a response.

---

## Types of Web APIs

There are three commonly used Web API styles:

### SOAP

* Highly formal and strict.
* Emphasizes robustness and well-defined protocols.
* Commonly used in **enterprise environments**.

### REST

* The **most popular and widely used** Web API style.
* Known for simplicity, scalability, and ease of integration.
* The primary focus of this course.

### GraphQL

* Designed for **precise and flexible data retrieval**.
* Minimizes data transfer by allowing clients to request exactly what they need.
* Optimized for performance.

## Working with APIs in Python

The course introduces two Python libraries used for interacting with Web APIs:

### urllib

* Comes bundled with Python.
* Very powerful but relatively **complex** to use.
* Requires multiple steps to:

  * Send a request using `urlopen`
  * Read the response using `read()`
  * Decode the response using `decode()`
  * Print or process the raw data

### requests

* An external library designed for simplicity.
* Handles many tasks automatically that require extra steps with `urllib`.
* Allows making API calls with minimal code using functions like `requests.get()`.
* Automatically reads and decodes responses.
* Response data can be accessed directly through attributes such as `response.text`.

Because of its ease of use, **requests** is preferred in this course.
