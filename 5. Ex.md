
# Creating and Deleting Resources Using an API

In this exercise, you will practice sending requests to specific API resources using different HTTP verbs. The focus is on interacting with the **playlists API** available at `http://localhost:3000/playlists/`.

## API Actions

| Verb   | Path                      | Description                                                                   |
| ------ | ------------------------- | ----------------------------------------------------------------------------- |
| GET    | `/playlists`              | Get a list of all playlists                                                   |
| GET    | `/playlists/{PlaylistId}` | Get information on a single playlist using its unique identifier `PlaylistId` |
| POST   | `/playlists`              | Create a new playlist                                                         |
| DELETE | `/playlists/{PlaylistId}` | Remove an existing playlist using its unique identifier `PlaylistId`          |

## Exercise Steps

### 1. Get a List of All Playlists

```python
import requests

response = requests.get('http://localhost:3000/playlists')
print(response.text)
```

### 2. Create a New Playlist

* Create a dictionary with the playlist information.
* Send a `POST` request to create the playlist.

```python
playlist_data = {'Name': 'Rock Ballads'}

response = requests.post('http://localhost:3000/playlists', data=playlist_data)
print(response.text)
```

### 3. Get Information on a Specific Playlist

* Retrieve information for the playlist with `PlaylistId` 2.

```python
response = requests.get('http://localhost:3000/playlists/2')
print(response.text)
```

### 4. Delete a Playlist

* Delete the playlist with `PlaylistId` 2.
* Confirm deletion by retrieving the list of existing playlists.

```python
requests.delete('http://localhost:3000/playlists/2')

response = requests.get('http://localhost:3000/playlists')
print(response.text)
```
