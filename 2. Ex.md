# Exercises: Making API Requests

## API Used in Exercises

The exercises use a **Music Catalog API**, starting with the **Lyrics API**, which returns a “Lyric of the Day”.

* **API Endpoint (URL):**
  `http://localhost:3000/lyrics/`

A URL (Uniform Resource Locator) specifies where an API can be accessed and where requests should be sent.

---

## Exercise 1: API Requests with `urllib`

### Objective

Make an API request using Python’s built-in `urllib` module and manually handle the response.

### Key Steps

1. Send a request using `urlopen`
2. Read the response data using `read()`
3. Retrieve the response encoding from headers
4. Decode the response bytes into a string
5. Print the decoded response

### Code Example

```python
from urllib.request import urlopen

with urlopen('http://localhost:3000/lyrics/') as response:
    data = response.read()
    encoding = response.headers.get_content_charset()
    string = data.decode(encoding)
    print(string)
```

### Key Takeaway

Using `urllib` requires explicit handling of response reading and decoding, which can make code longer and harder to read.

---

## Exercise 2: Using the `requests` Package

### Objective

Repeat the same API request using the `requests` library for a simpler implementation.

### Key Steps

1. Import the `requests` package
2. Send a GET request using `requests.get`
3. Print the response text directly

### Code Example

```python
import requests

response = requests.get("http://localhost:3000/lyrics")
print(response.text)
```

### Key Takeaway

The `requests` package automatically handles response reading and decoding, resulting in cleaner, more readable code.

---

## Summary

* APIs allow software systems to communicate programmatically
* Web APIs use HTTP and follow a client–server model
* REST is the most common Web API style and is the focus of this course
* `urllib` is powerful but verbose
* `requests` simplifies API integration and is preferred for most use cases
