# Constructing a URL with Parameters – Lyrics API

You can customize API requests by using **HTTP verbs**, **URL paths**, and **query parameters**. This exercise demonstrates making requests to the Lyrics API using the Python `requests` library.

---

## API Endpoint Components

| Component                   | Value                  |
|------------------------------|----------------------|
| Protocol                     | `http`               |
| Domain                       | `localhost`          |
| Port                         | `3000`               |
| Path                         | `/lyrics/random`     |
| Artist filter parameter      | `artist`             |
| Include track parameter      | `include_track`      |

---

## 1. Basic URL Request

Construct a URL to the random lyrics API:

```python
import requests

response = requests.get('http://localhost:3000/lyrics/random')
print(response.text)
````

---

## 2. Adding an Artist Filter

Use a **query parameter** to filter lyrics by a specific artist:

```python
query_params = {'artist': 'Deep Purple'}

response = requests.get('http://localhost:3000/lyrics/random', params=query_params)
print(response.text)
```

---

## 3. Including Track Information

Add another query parameter to include the track title in the response:

```python
query_params = {'artist': 'Deep Purple', 'include_track': True}

response = requests.get('http://localhost:3000/lyrics/random', params=query_params)

# Print the full URL with query parameters
print(response.url)

# Print the API response
print(response.text)
```

---

### Key Takeaways

* URL components: protocol, domain, port, path.
* Query parameters allow fine-tuning of API responses.
* `requests.get(url, params=...)` automatically encodes query parameters into the URL.
