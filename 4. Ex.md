# Exercise: Constructing a URL with Parameters

You can fine-tune your API requests using the path and query parameters of a URL. This exercise demonstrates how to use HTTP verbs, URL paths, and parameters with the `requests` library.

In this exercise, you will make an API request to the **Lyrics API**. Instead of fetching today's lyric, you'll request a **random lyric**. Later, you'll customize the request using query parameters to filter by artist and include the track title.

## API Details

| Component                  | Value                  |
|----------------------------|----------------------|
| Protocol                   | http                  |
| Domain                     | localhost             |
| Port                       | 3000                  |
| Path                       | /lyrics/random        |
| Artist filter parameter    | artist                |
| Include track parameter    | include_track         |

> **Note:** The `requests` library is already imported.

## Instructions (1/3)

1. Construct the URL to the random lyrics API using the **protocol**, **domain**, **port**, and **path** components.
2. Do not include query parameters yet—they will be added in later steps.
