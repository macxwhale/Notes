You can fine-tune API requests using **HTTP verbs**, **URL paths**, and **query parameters**. The `requests` library in Python makes this straightforward.

## Exercise: Random Lyrics API

Instead of retrieving today’s lyric, you can request a **random lyric** and customize it with query parameters.

### API Details

| Component               | Value          |
| ----------------------- | -------------- |
| Protocol                | http           |
| Domain                  | localhost      |
| Port                    | 3000           |
| Path                    | /lyrics/random |
| Artist filter parameter | artist         |
| Include track parameter | include_track  |

### Instructions

1. Create a dictionary for query parameters to filter by artist:

```python
query_params = {'artist': 'Deep Purple'}
```

2. Pass the dictionary to `requests.get()` using the `params` argument:

```python
import requests

response = requests.get('http://localhost:3000/lyrics/random', params=query_params)
print(response.text)
```

This will return random lyrics **only from the specified artist**.

### Example Solution

```python
import requests

# Define query parameters
query_params = {'artist': 'Deep Purple', 'include_track': True}

# Send GET request
response = requests.get('http://localhost:3000/lyrics/random', params=query_params)

# Print the full URL
print(response.url)

# Print the lyric
print(response.text)
```
